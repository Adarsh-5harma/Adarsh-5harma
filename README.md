## About Me

I'm a CS&AI student at **Lumbini Technical University**, Nepal, focused on building end-to-end intelligent systems — from raw data scraping to AI-powered normalization to production-ready APIs.

I don't just study ML theory. I build things that solve real problems:
- 🕷️ Multi-source web scrapers that handle inconsistent, messy retailer data
- 🤖 AI normalization pipelines using LLMs to clean and classify data at scale
- 📊 Django-backed REST APIs that serve clean, structured data downstream
- 🔍 Market intelligence tools for fragmented, unstructured industries

Currently building: **Phase 1 of a Fragrance Intelligence System** — connecting retail POS systems (Bsale, Shopify, VTEX) to a live inventory and pricing engine for the Chilean fragrance market.

> AI-powered data pipeline for Chile's fragrance retail market

Scrapes 4 wholesale importers → normalizes 1,163 products with Groq AI (llama-3.1-8b-instant) → stores in Django catalog with full price history. Fixed 805 gender fields and 92 perfume type fields at $0.00 cost using Groq's free tier.
