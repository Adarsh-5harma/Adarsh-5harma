## Featured Project

### 🌸 [Fragrance Intelligence System](https://github.com/Adarsh-5harma/fragrance-intelligence-system)
> AI-powered data pipeline for Chile's fragrance retail market

Scrapes 4 wholesale importers → normalizes **1,163 products** with Groq AI (`llama-3.1-8b-instant`) → stores in a Django catalog with full price history.

**Impact:** Fixed 805 gender fields and 92 perfume-type fields at **$0.00 cost** using Groq's free tier.

`Python` · `Django` · `Groq AI` · `BeautifulSoup` · `REST API` · `Web Scraping`
