## About Me

I'm a CS&AI student at **Lumbini Technical University**, Nepal, focused on building end-to-end intelligent systems — from raw data scraping to AI-powered normalization to production-ready APIs.

I don't just study ML theory. I build things that solve real problems:

- 🕷️ Multi-source web scrapers that handle inconsistent, messy retailer data
- 🤖 AI normalization pipelines using LLMs to clean and classify data at scale
- 📊 Django-backed REST APIs that serve clean, structured data downstream
- 🗄️ PostgreSQL schemas with relational models (Source/Listing/PriceHistory)
- 🔍 Market intelligence tools for fragmented, unstructured industries

Currently building: **Phase 2 of a Fragrance Intelligence System** — connecting retail POS systems (Bsale) to a live restock prediction engine for the Chilean fragrance market. Phase 1 complete: 15,057 products, 6 sources, fully automated pipeline.

## Featured Projects

### 🌸 [Fragrance Intelligence System](https://github.com/Adarsh-5harma/fragrance-intelligence-system)
> AI-powered market intelligence pipeline for Chile's fragrance retail market

Scrapes **6 Chilean wholesale importers** → hybrid regex + AI normalization pipeline using **Groq (llama-3.3-70b-versatile)** → **15,057 products across 477 brands** stored in PostgreSQL with full price history. Source/ProductListing/PriceHistory schema for time-series price tracking. Automated nightly via Windows Task Scheduler. AI cost: **$0.00**.

`Python` `Django` `PostgreSQL` `Groq AI` `BeautifulSoup` `REST API` `Web Scraping`
